# 绣坊协同 App 部署说明（PWA）

这套文件把「绣坊协同」做成了可安装到手机主屏幕的 PWA 应用。部署到免费静态托管后，手机浏览器打开网址、点「添加到主屏幕」即可像 App 一样全屏使用，并可离线打开。

## 文件清单

- `index.html` — 应用主文件（含业务功能 + PWA 支持 + 导入备份）
- `manifest.webmanifest` — PWA 配置（名称、图标、全屏模式）
- `sw.js` — Service Worker（离线缓存）
- `reset.html` — 手机端独立数据重置页（清空业务数据 / 恢复出厂演示数据）
- `icon-192.png` / `icon-512.png` — 应用图标

## 方案一：部署到 GitHub Pages（推荐，免费）

1. 注册 GitHub 账号，新建一个仓库（例如 `xiufang-app`），设为 Public。
2. 把本 `app` 文件夹里的 **5 个文件全部**上传到仓库根目录。
3. 仓库 → Settings → Pages → Source 选 `main` / `root` → Save。
4. 等待几十秒，得到网址：`https://你的用户名.github.io/xiufang-app/`
5. 手机浏览器打开这个网址 → 菜单 → 「添加到主屏幕」（安卓 Chrome 可能显示「安装应用」）。

## 方案二：部署到 Netlify（更简单，拖拽即可）

1. 打开 https://app.netlify.com/drop
2. 把本 `app` 文件夹**整个拖进去**（Netlify 会自动部署，自带 HTTPS）。
3. 得到一个 `https://xxx.netlify.app` 网址。
4. 手机浏览器打开 → 添加到主屏幕。

## 手机安装方法

- **安卓（Chrome）**：打开网址 → 右上角菜单 ⋮ → 「安装应用 / 添加到主屏幕」→ 确认。
- **iPhone（Safari）**：打开网址 → 底部分享按钮 → 「添加到主屏幕」→ 确认。
  - 注意：iPhone 必须用 Safari 打开，Chrome for iOS 不支持安装 PWA。

## 离线使用

首次联网打开后，应用会被缓存，之后没网也能打开。数据保存在手机浏览器本地（localStorage），不会上传。

## 重要提醒

1. **必须用 HTTPS 网址打开**才能安装 PWA。直接双击 `index.html`（file:// 方式）可以运行，但无法安装、无法离线。
2. **数据不会跨设备自动同步**。换手机/换浏览器时，用应用内「留痕 → 导出 JSON 备份」导出文件，再到新设备「导入 JSON 备份」导入。
3. 清理手机浏览器数据会清空本地数据，请定期导出备份。
4. 更新部署后，如果手机还是旧版本：关闭应用所有页面、重新打开；仍不行则在浏览器设置里清除该网址的缓存数据。

## 清空演示数据（正式使用前）

管理员视角 → **留痕** → 页面底部「数据管理」→ **清空演示数据**。

- 删除：全部演示订单、操作留痕、异常、代操作、现场照片、付款记录。
- 保留：人员名单、当前身份设置，可直接开始录入真实绣品单。
- 该操作不可恢复，建议先点「导出 JSON 备份」。
- 如误清，可点旁边的「恢复演示数据」。

每个设备 / 浏览器都要单独清空一次，数据不会跨设备同步。

更新代码后 sw.js 的缓存版本号会递增，手机下次打开自动拉取新版本。若仍是旧界面，可在网址后加 `?v=5` 打开一次强制绕过旧缓存，再改回正常网址。

**手机最省事的办法**：直接打开重置页面（把 IP 换成电脑的局域网 IP）：

```
http://192.168.68.184:8765/reset.html
```

页面上有两个大按钮：
- **清空业务数据（保留人员）**：删订单、留痕、异常、照片、付款，保留人员，适合正式使用前清零
- **恢复出厂演示数据**：连人员、设置一起恢复到初始演示状态

点完自动回到应用。

## 删除误建 / 卡住的订单

管理员视角 → 点开订单「详情」→ **🗑 删除订单** → 确认。

- 适用于误建、重复、发料后卡住（绣娘收不了、又无法取消）的订单。
- 删除时会二次确认，列出该单关联的付款 / 异常 / 代操作 / 照片数量；已结算单会额外警告。
- 会一并清除该订单的付款、异常、代操作、现场照片和操作留痕，并在留痕里新增一条「删除订单」记录。
- 仅管理员可见可用；删除不可恢复，建议先导出备份。
- 补充：「扫码收料」是**跟单员**的职责，绣娘视角本就没有收料按钮。发料后要由跟单员在「收料」页扫码收料，绣娘才能继续。

## 数据迁移（从旧电脑版迁移到手机版）

1. 在旧的 `绣品生产协同APP.html` 里：留痕 → 导出 JSON 备份，得到备份文件。
2. 把备份文件传到手机（微信/邮件/网盘均可）。
3. 在手机版：留痕 → 导入 JSON 备份 → 选择该文件 → 确认。

> 导入时若在弹出的确认框点了「取消」，可直接再次选同一个文件重试；选择框在选文件后立即复位，不会出现「点第二次没反应」。
>
> 注：根目录原件 `绣品生产协同APP.html` 只有「导出」没有「导入」；同目录的 `绣品生产协同APP_清零恢复版.html` 已补齐导入备份、清空演示数据、恢复演示数据。此 App 版四项功能齐备。

## 更新应用代码后

修改 `index.html` 后重新部署，并把 `sw.js` 里的 `CACHE` 版本号递增（当前为 `xiufang-v5`），这样手机下次打开会自动拉取新版本。当前策略为网络优先、失败回退缓存，递增版本号可同时清理旧缓存。
